## Why Make.com Pricing Scales Non-Linearly

Make bills per **operation**, not per workflow execution. A 12-node workflow that iterates over a 25-row JSON array consumes `1 + (25 × 11) = 276` operations on a single trigger.

At low volume, Make's Core plan looks cheap. Once you cross 100k–500k ops/month—especially with polling intervals or multi-step AI enrichment—you hit two walls:

1. **Per-operation overages** or forced jumps to Teams/Enterprise tiers.
2. **Execution concurrency limits**, requiring extra paid add-ons for parallel webhook bursts.

In contrast, **n8n** self-hosted has zero per-operation licensing fees. You pay strictly for compute, memory, and database backups.

## The Production n8n Architecture (Queue Mode)

Running n8n as a single container with SQLite works for local testing, but it **will** lock up under concurrent webhooks. In production, we split the stack into four services:

1. **n8n Main (`EXECUTIONS_MODE=queue`)**: Serves the UI and receives incoming webhooks, pushing jobs into Redis without blocking the event loop.
2. **Redis 7**: Holds the BullMQ execution queue and worker state.
3. **n8n Workers (2+ replicas)**: Pull jobs from Redis and execute HTTP requests, transforms, and LLM calls in parallel.
4. **PostgreSQL 16**: Stores credentials, workflow definitions, and execution logs (with `EXECUTIONS_DATA_PRUNE=true` so disk doesn't fill up).

```yaml
services:
  n8n-main:
    image: docker.n8n.io/n8nio/n8n:1.68.0
    environment:
      - EXECUTIONS_MODE=queue
      - QUEUE_BULL_REDIS_HOST=redis
      - DB_TYPE=postgresdb
      - EXECUTIONS_DATA_PRUNE=true
      - EXECUTIONS_DATA_MAX_AGE=168
    depends_on:
      - postgres
      - redis
```

## When You Should NOT Self-Host n8n

Self-hosting isn't automatically the right answer for every team:

- **Under 25k ops/month**: Stay on Make.com Core or n8n Cloud Starter. Your engineering time is worth more than saving \$15/month.
- **Zero Linux/Docker ownership**: If nobody on your team is comfortable rotating encryption keys or monitoring disk usage, managed n8n Cloud at \$60/mo is still 20× cheaper than Make at 100k ops.
